# Источники и notices исследовательского каталога

Эти JSON содержат идентификаторы, имена списков и проверенные сопоставления.
Движок, исполняемый upstream-код, payload-сигнатуры и полный доменный feed здесь
не распространяются. Production-пакет потребует собственного полного набора
notices и проверки лицензий всех включённых файлов.
