# Аудит интерфейса OpenMikroRout 0.3.2

Проверка выполнена на локальном деморежиме, без изменения сетевой конфигурации.
Сохранена структура WinBox: синее левое меню, светлая рабочая область, таблицы и
редакторы свойств с отдельным сохранением черновика и применением.

| Проблема                                                                               | Исправление                                                                                                                                                               |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Анимация заново начиналась при каждом ответе сервера и останавливалась между ответами. | Один непрерывный цикл следует за новыми значениями; разряды крупных показателей плавно прокручиваются.                                                                    |
| Некоторые дополнительные счётчики менялись без перехода.                               | Общий механизм отображения теперь охватывает также трафик, пакеты и аренды в карточках.                                                                                   |
| Единицы измерения часто менялись около границы масштаба.                               | Добавлен гистерезис; исходные измерения и сохранённая история не меняются.                                                                                                |
| Подписи ужимались до 6–7 px, длинные значения переносились или выходили за край.       | Две фиксированные строки для подписи и значения, шрифт 12–13 px, компактные тысячи/миллионы и подсказки с полными счётчиками. Основные значения уменьшают шрифт отдельно. |
| Пограничная планшетная ширина оставляла слишком узкие карточки.                        | На ширине до 1000 px используется две колонки; на телефоне — одна. Высота карточек не зависит от значения.                                                                |
| Повторяющиеся карточки и большие подсказки отвлекали от таблиц настроек.               | Сводка заменена компактной строкой; подробности работы с черновиком свёрнуты в раскрываемую справку.                                                                      |
| Мобильные поля с подписью сбоку были тесными.                                          | На узком экране подпись находится над полем; размер ввода 16 px.                                                                                                          |
| Мобильное меню не закрывалось клавишей Escape или нажатием по фону.                    | Добавлены фон, возврат фокуса, `aria-expanded`, блокировка фоновых элементов и закрытие при смене раздела/ширины.                                                         |
| Новый выбранный логотип не входил в опубликованный пакет.                              | Подключён предоставленный Folded Route в меню, обзоре, форме входа и favicon; обновлены адреса ресурсов для браузерного кэша.                                             |

## Проверки

- Основные разделы: обзор, Interfaces, Bridge, Addresses, Routes, DHCP Server,
  Pool, DNS, Firewall, Users, Updates и журнал. У кнопок действий есть подписи
  или доступные имена; горизонтальная прокрутка больших таблиц локальна.
- Ширины 320, 768 и 1440 px: отсутствие переполнения страницы и основных чисел,
  сохранение размеров карточек при обновлениях; дополнительные значения — 13 px.
- Резкие тестовые изменения скорости и пакетов с интервалом 200 мс: узлы чисел
  остаются теми же, высота карточек стабильна, цифры анимируются средствами браузера.
- Системное уменьшение движения: отсутствуют активные анимации и прокрутка разрядов.
- Мобильное меню: Escape, закрытие по фону, блокировка фона и возврат фокуса.
- Формы и графики проверяются в тестовом интерфейсе; ограничения ролей read/full
  продолжают проверяться существующими автоматическими тестами.
