# Отрицания фильтров списков

Кнопка **!** рядом с заполненным фильтром означает «показать всё, кроме
указанного». Несколько условий, в том числе отрицательных, соединяются через AND.
Пустое условие не инвертируется: очистка поля снимает его отрицание.

| Раздел | Условия с отрицанием |
| --- | --- |
| Firewall → Connections, оба режима | Источник, назначение, порт/диапазоны, протокол, состояние, интерфейс, поиск |
| NAT, панель над таблицей | Поиск, цепочка, протокол |
| WireGuard → Peers | Поиск, интерфейс |
| Neighbors | Поиск устройства, интерфейс |
| Security → Fail2ban | Поиск активных блокировок |
| Security → GeoIP | Поиск страновых списков |
| Содержимое системного Address List | Поиск адреса/сети |
| Packet Sniffer | Источник, назначение, порт, протокол |

Например, в Connections задайте источник `198.51.100.24`, включите **!** и
нажмите «Фильтровать»: обращения с этого адреса будут исключены. Для подсети
исключается вся сеть. Отрицание порта исключает совпадение с любым заданным
портом или диапазоном: учитываются source, destination и translated port.
Фильтр назначения Connections относится к исходному адресу назначения.

В формах с кнопкой поиска сначала задаются условия, затем запускается фильтрация.
NAT и WireGuard Peers фильтруются сразу. Обновление данных и сортировка сохраняют
условия; «Сбросить» в Connections очищает их вместе с отрицаниями.
Отрицания фильтров списков доступны пользователям read.

Внутри странового системного списка поиск CIDR выбирает диапазоны, пересекающиеся
с этой сетью; **!** исключает такие диапазоны целиком, не изменяя сам список.

Эти условия **не меняют правила Firewall, NAT, блокировки или конфигурацию**.
В Packet Sniffer они задают отбор заголовков следующего захвата; запуск, как и
раньше, требует full. Интерфейс захвата определяет источник данных и не имеет
отрицания. Произвольные BPF-выражения, параметры tcpdump и shell-команды не
принимаются. Во время захвата фильтры заблокированы.

Отрицания условий самих правил NAT/Filter описаны отдельно:
[MATCH-NEGATION.md](MATCH-NEGATION.md).
