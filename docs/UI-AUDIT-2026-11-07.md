# UI and forms audit — 2026-11-07

## Findings and corrections

| Area | Cause | Correction |
| --- | --- | --- |
| Port / Network Scan | A fieldset containing the complete form occupied one cell of a four-column tools grid; buttons stretched with adjacent cells. | Separate responsive field grid and content-sized action row; shared fieldset styling. |
| DNS, interface lists, bridge members, connection states, discovery permissions | Native multiple selects required modifier keys and hid selection intent. | Named checkbox groups, visible count, search, Select all / Clear; original FormData names and validation retained. |
| Overview | Every 200 ms sample generated and parsed the whole dashboard, including unchanged tables. | Numeric target updates and small chart patches; full rendering only when the structural signature changes; reused canvas. |
| NAT search and menu expansion | Whole app rendering replaced unrelated controls. | Update only rule rows/counts or sidebar navigation; retain current form and sidebar scroll. |
| Users / discovery polling | Identical responses replaced visible DOM. | Preserve existing DOM for unchanged results. |
| Localization | Mixed RU/EN source labels and fixed Russian number/country formatters. | Per-account RU/EN preference, cached static-template translation, locale-aware number/date/country formatting. |

## Data and access boundaries

Translation applies to developer-authored captions and accessible labels.
Interpolated account names, device names, addresses, comments, keys and config
values remain opaque. Template translation does not walk or observe the DOM.
Source action IDs, keyboard keys, form values and API paths remain canonical.
Catalog tests cover both languages, formatting whitespace, interpolation
placeholders and language changes after templates have been cached.

Only an authenticated user can save their own language. Both roles are supported;
extra identity/role fields and unsupported language values are rejected. Same-
origin and fresh-session checks remain. Account-security fields and network state
are not mutated by a language preference update. Old database and account backup
fixtures cover migration and restart behavior.

## Verification

- Automated UI coverage includes all router pages/editors, permissions, checkbox
  collection/validation, tab state, locale changes and existing telemetry behavior.
- Browser checks use an isolated demo database and synthetic accounts, never the
  production router configuration. Verified EN profile save followed by page
  refresh, checkbox changes, form retention while expanding navigation, scanner
  button bounds and desktop/mobile layouts (1280×720 and 390×844).
- Instrumented 128-interface telemetry: full HTML 233,565 characters versus 5,189
  characters for the two incremental chart regions before catalog text changes;
  one canvas across six samples; existing numeric DOM identity retained.
- Python account migration/restore/authentication tests and static gzip/cache/API
  separation checks pass. Python and UI gate totals are recorded in the release
  validation output.

These checks cover forms and presentation. They do not simulate every production
network size, browser extension or low-power device.
