# Оконный рабочий стол OpenMikroRout

Меню открывает независимые окна внутри текущей вкладки браузера. Одновременно
можно работать с обзором, интерфейсами, NAT, Ping, перехватом пакетов и другими
разделами. Повторный выбор раздела поднимает его окно. Подвкладки одного раздела
используют то же окно.

## Поведение

- Заголовок перемещает окно; края и углы меняют его размеры.
- Сворачивание сохраняет формы, выделение и работающие инструменты. Нижняя панель
  позволяет вернуться в любое открытое окно.
- Пункт «Открытые окна» внизу левого меню показывает полный список, свёрнутые окна
  и выполняющиеся операции. Выбор строки восстанавливает и поднимает нужное окно.
- Разворачивание, восстановление, привязка слева/справа, каскад, размещение рядом
  и сбор окон управляют расположением без перезагрузки инструментов.
- Масштаб содержимого меняется отдельно от размеров окна в пределах 80–125%.
- На телефоне инструменты представлены полноэкранными панелями с переключателем.
- С клавиатуры: Tab переводит фокус на заголовок, Alt + стрелки перемещают окно,
  Alt + Shift + стрелки меняют размер. Двойной щелчок по заголовку разворачивает окно.
- Закрытие потокового инструмента завершает его операцию. Для активного
  серверного сканирования предлагается продолжить задание в фоне или остановить.
- Несохранённые формы требуют явного подтверждения закрытия. Сохранённый на
  сервере сетевой черновик остаётся общим; панель применения и таймер подтверждения
  связи видны вне окон.

## Архитектура

Оконный менеджер сохраняет постоянный DOM каждого инструмента. Рабочий документ
инструмента загружается из `/workspace-frame` того же origin. Это изолирует
существующие JavaScript-модули, их `document`, формы, фильтры и редактор без
введения нового framework или переписывания всех компонентов.

Реестр определяет доступные инструменты, их группы подвкладок и размеры. Менеджер
отвечает за геометрию, фокус, наложение, масштаб и панель окон. Мост подключает
только зарегистрированные документы своего origin, управляет видимостью и
освобождением ресурсов и передаёт только метаданные состояния инструмента.

Общие безопасные JSON GET-запросы объединяются координатором основной страницы;
каждый получатель получает отдельную копию ответа. Изменения конфигурации
инвалидируют общий кеш и обновляют остальные окна. Проверка ревизий на сервере
остаётся обязательной. Записи, пароли, ключи, архивы, авторизация и потоковые
ответы не кешируются координатором.

До завершения загрузки или сохранения выбор подвкладки ставится в очередь;
применяется последний выбранный раздел. Фоновое обновление проверяет изменения
форм повторно после загрузки данных и сохраняет начатый ввод. Конфликт ревизии
показывается при сохранении, без автоматической перезаписи чужого черновика.

Только `/workspace-frame` разрешает встраивание со своего origin. Основная
страница и API сохраняют запрет встраивания; внешние документы не разрешаются.
Права read/full, CSRF, авторизация API и проверка живых сессий остаются серверными.

## Сохранение и ресурсы

Локально, отдельно для пользователя и роутера, сохраняются только идентификаторы
открытых разделов, размеры, координаты, масштаб и состояние окон. Содержимое форм,
вывод команд и пакетов, пароли, ключи и токены в раскладку не входят. Восстановление
раскладки не запускает команды и сканирование автоматически.

Свёрнутые окна продолжают получать результаты работающих потоков, сокращая
обновления DOM. Обзор использует историю из базы роутера. На сервере по-прежнему
допускается одна активная диагностика, один захват и одно сканирование в своих
подсистемах; окна показывают занятость и сохраняют ответы сервера.

Наблюдение за установкой обновления принадлежит главному документу. Оно сохраняет
только номер версии и переживает закрытие окна Updates и завершение сессии при
перезапуске. После успешной проверки нового сервиса обновляется вся страница;
JS/CSS по-прежнему требуют обязательной проверки кеша сервером.

Обновление 0.8.0 не требует миграции базы и не меняет сетевую конфигурацию.
Кнопка «Сбросить раскладку» возвращает размеры и масштаб текущих окон к значениям
по умолчанию, сохраняя открытые формы и работающие операции.
