# Составные фильтры AND / OR

Фильтрация списков настраивается в едином визуальном конструкторе. Он позволяет
собрать запрос из строк «поле → оператор → значение», объединять условия через
**И (AND)** и **ИЛИ (OR)**, а также создавать вложенные группы со скобками.
Условия и группы можно удалять по отдельности.

## Пример для Connections

1. Откройте Firewall → Connections → «Расширенный фильтр».
2. В корневой группе оставьте И (AND), добавьте условие «Протокол равно TCP».
3. Добавьте группу, выберите для неё ИЛИ (OR).
4. В ней добавьте «Порт входит в 443,3389» и «Назначение входит в 203.0.113.0/24».
5. Нажмите «Применить фильтр».

Получится `TCP AND (port ∈ {443,3389} OR destination ∈ 203.0.113.0/24)`.
Границы групп видны в интерфейсе: порядок AND/OR определяется скобками.
Все условия отображаются в конструкторе и применяются кнопкой «Применить фильтр».
Для исключения значения выберите «не равно», «не содержит» или «не входит».

## Поля и операторы

| Тип поля | Доступные сравнения |
| --- | --- |
| Текст | Равно, не равно, содержит, не содержит, пусто, не пусто |
| Значение из списка | Равно, не равно, входит в список, не входит, пусто, не пусто |
| IPv4 | Равно / не равно адресу, входит / не входит в сеть или список сетей |
| Порт | Равно, не равно, диапазоны, больше / меньше и включающие границу сравнения |
| Счётчик | Равно, не равно, больше, меньше, не меньше, не больше |

Набор операторов зависит от поля и раздела. Текст сравнивается без учета
регистра Unicode. Числовые значения передаются строками и сравниваются точно;
экспоненциальная запись не принимается. Для списков значений используются запятые.
IPv6 не поддерживается.

В Connections общий «Порт» проверяет source, destination и translated port;
отрицание исключает совпадение с любым из них. Отдельные поля портов позволяют
уточнить сторону. «После DNAT · IPv4» относится к конечному адресу назначения.
Отсутствующее значение не совпадает с положительным условием; отрицательное
условие является его дополнением. Используйте «не пусто», чтобы исключить
записи без нужного значения, например без DNAT.

В системном страновом списке адресный запрос проверяет пересечение диапазона
с выбранной сетью. Составные OR-условия сохраняют границы открытого списка,
страны или профиля. Само содержимое списков не изменяется.

## Где доступен

Connections (активные соединения и входящие попытки), NAT, WireGuard Peers,
Neighbors, активные блокировки Fail2ban, страны GeoIP, содержимое системных
Address Lists и Packet Sniffer. В каждом разделе предлагаются его поля.

Фильтры списков доступны read-пользователям. Запуск Packet Sniffer по-прежнему
требует full: его составной фильтр отбирает заголовки следующего захвата.
Интерфейс захвата выбирается отдельно. Во время захвата конструктор заблокирован.

## Ограничения и API

До 16 условий, 31 узла, четырех уровней вложенности, 128 символов на значение
и 4096 байт JSON. Незавершенные строки и пустые вложенные группы нужно заполнить
или удалить перед применением. Очистка корневой группы отключает расширенный
фильтр после применения. Обновление данных не применяет незавершенный запрос.
Состояние редактора хранится в текущей сессии интерфейса и очищается при выходе.

Мониторинговые GET-запросы принимают необязательный параметр `expression` с JSON.
Packet Sniffer принимает объект `expression` в своем POST-запросе. Формат:

```json
{
  "kind": "group",
  "join": "and",
  "children": [
    {"kind": "condition", "field": "protocol", "op": "eq", "value": "tcp"},
    {"kind": "condition", "field": "source", "op": "not_in", "value": "192.0.2.0/24"}
  ]
}
```

Поля и операторы проверяются отдельно для каждого раздела. Выражение применяется
до подсчета и пагинации; SQL-параметры и BPF формирует сервер. Произвольные SQL,
BPF и shell-команды не выполняются. Фильтры отображения не меняют политику NAT,
Firewall или Fail2ban. Миграция базы данных не требуется.

Для совместимости интеграций API сохраняет прежние отдельные параметры запроса
и `negate`. Если внешний клиент передаёт их вместе с `expression`, сервер
объединяет эти ограничения через AND. В веб-интерфейсе условия задаются
в конструкторе.
