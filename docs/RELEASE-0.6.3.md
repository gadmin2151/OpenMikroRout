# OpenMikroRout 0.6.3

## Защита сервиса прямо в правиле

В **IP → Firewall → NAT / Filter Rules → Fail2ban** включите автоматическую
блокировку и задайте количество попыток, период подсчёта и время бана. Профиль,
jail, временный список и правило блокировки создаются из исходного правила.
Отдельно создавать профиль и повторно вводить порты больше не нужно.

- Для DNAT используются конечный адрес и порт после трансляции; учитываются
  оба пути — локальный INPUT и транзитный FORWARD.
- Входной интерфейс и Interface List берутся из правила. В Filter сохраняются
  ограничения назначения, выходного интерфейса и Dst. Country.
- Изменения, выключение и удаление правила синхронизируют защиту при применении.
  Снятие оставшегося бана доступно и после удаления исходного правила.
- Security → Fail2ban показывает автоматически защищаемые сервисы и открывает
  исходное правило для редактирования. Ручные профили Web / SSH сохранены;
  их выключатель не отключает защиту правил.
- Старое условие совпадения с ban list сохранено в **Advanced**.

**TCP-попытки не являются ошибками пароля.** Для серверов за NAT учитываются
попытки новых TCP-подключений; для ошибок пароля Windows/RDP нужны журналы
целевого сервера. Источники ошибок Web / SSH относятся к самому роутеру.
Новая защита выключена по умолчанию и не включается самим обновлением.

Сборщик использует приватную группу NFLOG 5088 и метаданные conntrack, без
содержимого пакетов. Повторные SYN не увеличивают порог. Журнал, кэш и поток
событий ограничены; потери и недоступность сборщика видны в Security.
Подробности и ограничения: [защита и исследование сети](SECURITY-DISCOVERY.md).

## Навигация в стиле WinBox

- IP → Firewall объединяет Filter Rules, NAT, Address Lists и Connections.
- Interfaces, Bridge и WireGuard вынесены на основной уровень.
- Security содержит Fail2ban и GeoIP, Tools — диагностику и сканирование,
  System — управление приложением; журнал доступен в Log.
- Добавлены пояснения, счётчики записей и полный путь текущего раздела.
  Preview находится в панели действий страницы. Прокрутка меню сохраняется.
- На узких экранах названия вложенных пунктов остаются читаемыми; мобильное
  меню закрывается после выбора раздела.

## Обновление и совместимость

Обновление распространяется подписанным пакетом для **System → Updates**.
Пользователи, 2FA, пароли, сетевые правила и неприменённый черновик сохраняются.
JSON/RSC версии 0.6.2 остаются совместимы; существующие NAT/Filter без новой
защиты компилируются без изменения поведения.

Для native Linux один раз установите системные зависимости и приватный
Fail2ban companion по [инструкции](SECURITY-DISCOVERY.md#перед-первым-включением).
Для TCP-сборщика требуются `nfnetlink_log`, `nf_conntrack_netlink` и `xt_NFLOG`;
обновлённый `deploy/install-fail2ban.sh` подготавливает их. Пакет обновления не
запускает пакетный менеджер ОС и не меняет чужие firewall/jail-профили.

- Python: 520 тестов прошли, 12 платформенных проверок пропущены на macOS;

- Linux: 94 существующих kernel/bootstrap сценария и 3 новых NFLOG-сценария
  прошли в изолированных контейнерах / сетевых пространствах имён.
- Реальные Fail2ban → ipset ban/unban, повторные SYN, область защищаемого порта,
  запуск/остановка companion и откат при остановке сервиса проверены.
